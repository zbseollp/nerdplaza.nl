			<h2>WhatsApp op pc</h2>		
		<p>Om WhatsApp op je pc te gebruiken, moet je eerst de <b>WhatsApp app</b> op je telefoon hebben geïnstalleerd. Vervolgens kun je de<b> WhatsApp Desktop app downloaden</b> vanaf de officiële website of via de <b>Microsoft Store voor Windows</b> of de<b> App Store voor Mac</b>. Nadat je de app hebt geïnstalleerd, kun je je telefoon verbinden met de desktop app door het<b> scannen van een QR-code</b>.</p>

			<h2>WhatsApp inloggen zonder telefoon</h2>		
		<p>Hoewel het nodig is om je telefoon te gebruiken om de eerste verbinding met WhatsApp Desktop of Web tot stand te brengen, <b>hoef je daarna niet voortdurend verbonden te blijven</b>. Je kunt gewoon doorgaan met chatten vanaf je desktop, <b>zelfs als je telefoon offline is</b>.</p>		
			<h2>WhatsApp web zonder telefoon</h2>		
		<p>Het is momenteel <b>niet mogelijk </b>om in te loggen op WhatsApp Web <i>zonder </i>je telefoon. Bij de <b>eerste koppeling </b>via de QR-code is een telefoon vereist. Daarna kun je echter WhatsApp blijven gebruiken op je computer, <b>zelfs als je telefoon geen internetverbinding heeft</b>.</p>
